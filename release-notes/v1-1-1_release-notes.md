# Dev Notes - August 10, 2026
## 🚀 Version 1.1.1 : Snezhnayan Kickoff!

Finally, Snezhnaya is here! The long awaited region in the game as finally come. With that, I am also updating the web app to align with the release.

### 🌟 What's New?

In this version, there are not much changes regarding with the main program.
Instead, we are tweaking the character list configuration, and announcing the availability of the following characters:
- Sandrone
- Alyosha
- Odette

While I understand that there are characters listed who are *yet to be released* in the future updates of Genshin Impact, they are there for future reference. In the meantime, you can place a substitute using the **Custom Character** feature.

### 🤔 Future Additions

In light with the new region, Snezhnaya, I'll do my best to add the latest assets here as part of the web app. This includes the *background* and the *characters*.

In the meantime, you can add a **Custom Background** or a **Custom Character**. These custom features are designed for times like these, in case no assets yet have been added to the version.
