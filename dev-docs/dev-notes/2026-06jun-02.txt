=========================================
      GENSHIN CHAT - UPDATE CHANGELOG
=========================================
Session: June 2, 2026

Hey there! Here is a breakdown of all the awesome new features and Quality of Life (QoL) improvements we designed, planned, and implemented in this coding session. Everything was built keeping the code pure Vanilla JS, CSS, and HTML.

-----------------------------------------
1. THEME VARIABLES (CSS Clean-up)
-----------------------------------------
* What we planned: Create a central place for colors so we don't have to keep copy-pasting hex codes.
* What we did: 
  - Added a `:root` block to the top of the stylesheet.
  - Defined all main backgrounds, text colors, and unique element color accents.
  - Defined custom, thematic colors for every nation (Mondstadt, Liyue, Inazuma, Sumeru, Fontaine, Natlan, Snezhnaya).
  - Swapped out hardcoded colors for these variables. Now, editing the theme in the future is as easy as changing one variable!

-----------------------------------------
2. NATION HOVER EFFECTS
-----------------------------------------
* What we planned: Make character items in the Sender/Receiver list highlight with their specific nation's theme color when hovered.
* What we did:
  - Leveraged the `data-region` attribute already present on the character buttons.
  - Added CSS hover rules for each region to show a beautiful, color-coordinated gradient.
  - Added a subtle left-border highlight to match their respective elements (e.g., gold for Liyue/Geo, teal for Mondstadt/Anemo, purple for Inazuma/Electro).
  - Used smooth transitions so the colors fade in and out elegantly, without causing the text or list items to jump around.

-----------------------------------------
3. BACKGROUND SWITCHER
-----------------------------------------
* What we planned: Allow changing the app's background image dynamically via the Settings pane using a simple left/right selection layout.
* What we did:
  - Added a new "App Background" section to the Settings panel with previous `<` and next `>` buttons.
  - Created a list of 10 available backdrops matching Mondstadt, Liyue, Inazuma, Sumeru (Forest & Desert), Fontaine, Natlan, Nod-Krai, and domain party setup screen backgrounds.
  - Wrote JS logic to cycle through the backgrounds seamlessly and update the screen instantly.
  - Enabled "persistent memory" using local storage, meaning the app will remember your chosen background even if you refresh or close the browser!

-----------------------------------------
4. INTERFACE ZOOM & FONT SCALING
-----------------------------------------
* What we planned: Let users customize how large or small the interface looks so it fits perfectly on screens of all shapes and sizes.
* What we did:
  - Added an "Interface Zoom" control under the Settings pane with `[-]` and `[+]` buttons.
  - Configured the main styling stylesheet to scale relative to the root font-size.
  - Added JS click listeners that increase or decrease the interface zoom scaling in 10% steps (clamped safely between 70% and 150%).
  - Enabled local storage persistence for this setting too, so your zoom preference is saved!
